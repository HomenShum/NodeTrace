P1 · Native and pointer selection leave contradictory entity readouts

Pointer select tool workSurface.trace, then native-select actor trace-coach. The owned producing-event readout changes, while the vendor entity/count/visits panel keeps the tool. Root cause: Owner selectedId and vendor selected message are separate state; native selection never updates the vendor state.

Evidence: `E6c-nodetrace-independent-host/pointer-then-native-other.png`, `E6c-nodetrace-independent-host/pointer-then-native-other.json`.

Required knockout: Pointer to native to clear to a new selection must update every readout to the same current entity in source and installed consumer.

P1 · Same-ID data growth leaves old visit metadata

After replacing six traces with twelve using new event IDs and unchanged entity identities, the selected tool has two producing events but its visits panel stays at one. Root cause: The vendor reads mutable graph attributes during render before its effect patches attributes; same-ID changes do not increment rev, so there is no follow-up render for the changed visit count.

Evidence: `E6c-nodetrace-independent-metadata-replay/same-entities-extra-events.png`, `E6c-nodetrace-independent-metadata-replay/same-entities-extra-events.json`.

Required knockout: Retain selection across same-ID props replacement; event IDs and visit count must both describe the new snapshot without another user action.

P1 · Removing the hovered node leaves the whole graph dimmed

After removing the currently hovered tool, the remaining twelve entities all turn grey and labels disappear. Pointer-out and Fit do not recover the state. Root cause: The renderer closure retains hoverRef.current after that ID disappears from the graph. Every remaining node fails the stale-neighbor predicate and is dimmed; the stale hover is not cleared by the graph patch.

Evidence: `E6c-nodetrace-independent-hover-isolation/hovered-entity-removed.png`, `E6c-nodetrace-independent-hover-isolation/removed-entity-pointer-out.png`, `E6c-nodetrace-independent-hover-isolation/removed-entity-fit.png`.

Required knockout: Remove/replace the hovered entity during the same mount, keep the pointer still, then move out and Fit; remaining nodes and labels must return to their normal state.
