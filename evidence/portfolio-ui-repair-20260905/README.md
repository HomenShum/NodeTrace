Historical absolute paths inside raw receipts identify the original capture environment; the adjacent folders contain the portable copies. The external portfolio packet retains earlier failed/intermediate runs.

- `source-before/` and `installed-before/`: real pre-edit screenshots and marked scope.
- `quiet-audits/`: lab TBT 320/234 ms, axe zero. Earlier 842/900 ms failures are retained in the portfolio packet. No separate source-hash snapshot was taken during this audit; its served-tree guard and matching build assets are supporting evidence, not a retrospective source receipt.
